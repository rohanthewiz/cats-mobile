## grmob (v0.2.3, pushed)

1. **`8a9d50c` renderers.** Column/List/Scroll with no cross-axis
   alignment stretch children on both natives (CSS default; explicit
   `Width` or inline `Display` hugs, so themed Buttons and Badges keep
   hugging). `core.SafeArea` is variadic like the other containers and
   `components.Screen` forwards only its background to it; iOS extends it
   with `ignoresSafeArea`. `GrMobScroll` on iOS measures its viewport off a
   background `GeometryReader` and floors a FlexGrow child at that height
   (`GrMobGrow.minHeight`). Modal's default surface steps aside when a
   direct child paints a background (Compose drops the white card; iOS sets
   `presentationBackground`).
2. **`fbf765c` lifecycle.** `core/lifecycle.go` (`CurrentLifecycle`,
   `OnLifecycle`, `ReceiveLifecycle`; dedupes repeats, drops unknown
   states), `hooks.UseLifecycle`, `"lifecycle"` host event with `state`.
   Android `AppLifecycle.kt` on `ProcessLifecycleOwner` (new
   `lifecycle-process:2.6.2` dep; the Activity would fire on every
   rotation); iOS `AppLifecycle.swift` on `scenePhase` at the App; web
   `visibilitychange`. `mobile/verify/lifecycle_test.go` pins the spellings.
   ROADMAP item checked; `docs/platforms/native.md` gained a Lifecycle
   section and a stretch-default paragraph; `wasm.md` mentions both.

   (`hostEvent` is). v0.2.2 shipped without it — grmob's `ios/verify`
   type-checks `Runtime/*.swift` only, not `App/`. Caught by this repo's
   `scripts/build-ios.sh --sim`.

## Gotchas

- grmob's `ios/GrMobApp.xcodeproj` is gitignored and regenerated by
  xcodegen from `project.yml` (`sources: [GrMob]`), so a new Swift file
  under `ios/GrMob/` needs no project edit.
- `ios/verify/run.sh` only type-checks `Runtime/`; anything under `App/`
  (system events, lifecycle) is first compiled by a real xcodebuild. Run
  `scripts/build-ios.sh --sim` from cats-mobile before tagging a grmob
  release that touches `App/`.
- A pushed tag is never moved: the actor fix went out as v0.2.3.
- `scripts/build-*.sh` must be run from cats-mobile (they `cd` relative to
  themselves; the grmob checkout is `../grmob`).
- Background-task exit codes: the harness reported the failed iOS build as
  exit 0 because of the trailing `echo`; read the log's `EXIT` line.
